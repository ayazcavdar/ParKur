Account & Locale

These values are written to the first-boot provisioning config and consumed by the systemd one-shot service that runs after the rootfs is bootstrapped. The config file is shredded immediately after first-boot completes.

The user account is granted sudo privileges. Auto-login is configured for the detected display manager (LightDM / GDM3 / SDDM).

Host Volume & Image Size

Pick an existing NTFS volume to host C:\NextOS\root.disk. No physical partitions are created, modified, or shrunk. The image is pre-allocated to your selected size (valid-data length set so NTFS does not zero-fill on write).
